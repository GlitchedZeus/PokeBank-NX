# Thread S handoff — shared Gen III–V editor (`claude/shared-editor-gen35-20261016`)

Base: #307 application branch `claude/gen5-integration-20261014`. It was merged forward at `eb0feb0`; forward merges only.

## Shared contract unit (Priority 1, pushed at `7fd8d0e`)

| Header | What it gives every generation |
|---|---|
| `include/UI/SharedMovesPanel.h` | The one MOVES panel: 4 slots, fixed PP cur/max and PP Ups columns, a status column, and a second line with type / category / Pwr / Acc. Also the one compact Move chooser row (No., name, type, category, Pwr, Acc, PP). |
| `include/UI/SharedMoveFacts.h` | Generation-correct move facts. Gen I–III show no per-move category, because it follows the type. A move outside the generation's table never exists there. |
| `include/Names/MoveTypes34.h` | Gen III types and Gen IV type + category. Generated by `tools/gen_move_types34.py` from pinned Showdown, with PP cross-checked against pinned PKHeX. |
| `include/UI/SharedEditorPresentation.h` | Picker footer (always ends A Select / B Cancel); confirm footer; `kOriginLegalityHeading` and honest legality labels; inline toggles (Shiny, Pokérus bytes, Gender by ratio, Gen III language); DETAILS viewport model. |
| `include/UI/SharedEditorChrome.h` | Footers drawn with the existing ScreenChrome glyphs. `beginModal()` drops the covered layer's touch targets, the same rule as Gen2WorkspaceLayers. |
| `include/UI/SharedStatReroll.h` | Y re-roll of IVs/EVs. |
| `include/Names/LocationDisplayNames.h` | Player-facing met-location names: no source tags, no raw ids. |

## Done on this branch

- **Phase 1:** Gen III, plus the shared Gen IV/V surface, draw the shared Moves panel and chooser in Create, Edit and View. X sorts the chooser. Moves that don't exist in the generation are filtered out of the picker.
- **Phase 3:** one action order — View, Edit, Clone, Move, Release, Origin & Legality, Review, Cancel. Make Shiny and the placeholder rows are removed. This is in `NarrowPokemonActionMenu.h`, Gen IV `gen4Actions`, and the Gen V bridge.
- **Phase 4:** "Origin & Legality" is the action label, the modal heading and the provenance pane title for Gen III–V. Status labels are honest: Not checked / Incomplete.
- **Phase 5:** the "Rows N-M/T" counter is gone. The DETAILS viewport is 8 rows and ends above the panel edge (static_asserts); touch hitboxes follow the same viewport.
- **Phase 6:** Y re-rolls IVs/EVs immediately with a new result each press. PID-derived traits are kept by construction. Tested with 42 drafts × 120 presses on the real PK3/PK4/PK5 code.
- **Phase 7:** every Gen III–V picker and the move editor use the shared footer and own the touch layer, as does the unsaved-changes dialog.
- **Phase 10:** Pokérus is an inline toggle (Gen III/IV/V). Language is inline in Gen III (skips languages the names can't fit) and Gen IV. Gen V language stays read-only, as the format requires. Shiny and Gender were already inline.
- **Phase 11:** clean location names. The Gen III encounter picker is 900 px with name left and method/level right; Gen IV/V use the same row style.
  - Met dates: Gen III stores none. Gen V shows YYYY-MM-DD (never a time of day).
  - Gen IV PK4 does store met/egg dates (0x78–0x7D), but the repo has no getter, so nothing is shown and nothing is invented.
- **Phase 2 (partial):**
  - Gen IV bag: `gen4QuantityRule()` is the single per-item query. Unique items (Key Items, HMs) get no numpad, either on A or on Add. Remove is already Y→Y confirmed.
  - Gen V: Key Items and TMs/HMs are already read-only.
