## Method

- **Retained set** = every KEEP / KEEP-PAUSED branch tip plus every tag that exists on the remote (110 distinct commits).
- **Unique commits** = `git rev-list <tip> --not <retained set>` (a retained branch is compared against the *other* retained refs).
- **Patch equivalence** = `git patch-id --stable` of each unique non-merge commit against all retained history; **tree equivalence** = the tip's tree equals the tree of a retained commit.
- **Content status:** MERGED (fully contained), SUPERSEDED (all patch-equivalent), DUPLICATE (same tip as another branch), UNIQUE (at least one commit with no equivalent).
- **Classification:** ACTIVE, PAUSED (Gen VI-IX / legality: preserved, never plain-deleted), MERGED, SUPERSEDED, DUPLICATE, ABANDONED-UNIQUE.
- **Evidence check:** for every non-retained branch, each blob at its tip under `docs/hardware/`, `docs/qa/`, `docs/qa-archives/`, `docs/handoffs/`, or named `RETEST_*`, `ROUND*_RESULTS*`, owner intake, screenshots or `*DEVICE_TEST*` / `*HARDWARE*` documents must exist in retained history, otherwise the branch cannot be DELETE-SAFE.
- GitHub keeps `refs/pull/<n>/head` for every PR even after a branch is deleted. That is an extra safety net, **not** counted as preservation here.
