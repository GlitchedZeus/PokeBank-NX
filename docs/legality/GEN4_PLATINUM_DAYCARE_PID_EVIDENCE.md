# RNG-005 / BREED-005 — Platinum original ordinary daycare egg-PID evidence

**Scope:** one independently source-attested Platinum ordinary daycare PID-creation stage, **not** the whole egg generation pipeline, and not D/P or HGSS. The source-pinned Platinum `Daycare_GetParentToInheritNature`, `Daycare_SetInheritedNature`, `Egg_SetInitialData` in [pret/pokeplatinum daycare.c at 637bb186](https://github.com/pret/pokeplatinum/blob/637bb186e11b5ce1ee578981311c057498e57126/src/overlay005/daycare.c) provide the source algorithms. Gen IV Everstone item ID 229 is pinned by the item index table.

**Source mechanics:** The eligible nature donor is selected from the original physical daycare pair: the last female found, overridden by the last Ditto found; double Ditto cannot be used as a compatible pair. If the selected donor holds an **original-stage Everstone**, a 16-bit LCRNG output less than `0x7FFF` selects a nature-inheriting loop (the boundary `0x7FFF` itself fails). Otherwise the stage consumes one MTRNG 32-bit PID. The inherited-nature branch samples successive MT outputs until the first **nonzero** PID with nature `PID % 25` matching the donor, with the original source's 2401-attempt fallback. Our evidence replay supports **64 original consecutive, externally attested MT outputs**; if no eligible PID is found within this budget, return **Unknown**, because the retail loop may run farther. A matching historical MT draw trace must be independently attested to begin exactly at egg creation and terminate at the real accepted stage; a random matching nature is not evidence.

**International language stage:** At original egg creation, `Egg_SetInitialData` checks original parent-language difference. If different and the selected PID is not shiny relative to the independently verified **daycare trainer's original 32-bit ID**, up to four `ARNG_Next(pid)=0x6C078965*pid+1 (mod 2^32)` transformations are tried, ending early on a shiny result. If already shiny, none are applied. This is distinct from Gen IV wild Method J/K LCRNG correlation. The result is checked against the actual immutable source-attested **unhatched** encrypted PK4. An original egg does not store MT boundary, Everstone activation roll, original collection-time items, parent-language difference or parent stage tokens.

**Guardrails:** Three nonzero independent history stage IDs must identify the **same** original daycare egg-creation moment. Both native parents must be valid non-eggs from a verified original Platinum group; the original child must be a valid immutable unhatched PK4 from the same group. Source stage parent-role, original Power/Everstone history, trainer ID, language and MTRNG sequence evidence must be separately verified. Input pair compatibility is a historical independent attestation, not inferred from the present stored parents. Missing info remains Unknown; failed PID equality only contradicts the independently supplied particular historical candidate. A candidate cannot be globally declared Invalid for failing one original MT hypothesis.

**Alternatives:** `evaluateUniverse` supports up to eight unique, independently grounded candidate histories against the **same original encrypted unhatched egg bytes**. Only a fully method-attested candidate-local PID mismatch can count toward an all-negative set. All negative requires independently complete enumeration of original Platinum ordinary daycare PID routes. Even then it cannot disprove events, gifts, different source games or other original egg origins. This is not a global Valid/Invalid engine.

**Regressions:** Synthetic valid encrypted original PK4 records demonstrate female Everstone at 0x7FFE vs failed flip 0x7FFF, Ditto overriding a female, a male-held Everstone not granting female nature, nonzero nature-match rejection/acceptance, international ARNG, already-shiny bypass, bounded search exhaustion, malformed/missing original evidence and full/missing archive enumeration, while protecting immutable original bytes. These are **synthetic stage witnesses, not genuine paired retail histories**.
