This is a repair checkpoint, not a completion claim. The official comparison remains PKHeX26.10.18 at `bfe89c74a3f5265805e364b79bc04ad38ebbc5ea`. Native III/IV and hatched V recursive adapters remain missing. No PR307 code, branch merge or app/device build is part of this change.

## Source-backed order repair

The newly inspected [published B2W2 day-care reconstruction](https://github.com/fuddlesworth/pokebw2/blob/9cb65bafa3e0198e6951a2fda6cc1c3470c67419/src/ov036/day_care.c) traverses the **child's learnset** in `inheritLvlUpMoves`. Both parents must know each move. Egg and TM phases traverse the father's slots; TM item traversal is nested inside that slot traversal. A known move is skipped, and only a new move displaces the oldest full slot.

The old forward certificate used paternal slot order for shared level-up moves. `BreedingBirthMoves.h` now uses child order in V, retaining the original III/IV traversal. An order-dependent Black/White certificate also has to survive the prior traversal; the B2W2 body is not silently treated as an independent native BW replay.

The published project identifies English US/EU B2/W2 ROM hashes and reports matching C bodies. We verify pinned Git blobs and SHA256, execute unchanged named bodies with isolated data/accessor stubs, and cross-check Pidgey's complete level/egg/machine row against its separately pinned native JSON. We have **not independently rebuilt those ROMs or run hardware acquisition**. `BW2_BREEDING_SOURCE_PINS.json` records that scope. Original BW, other regional binaries, complete parental ancestry, item issuance and original specimen custody are not certified by this replay.

The new necessary-order rejection is restricted to ordinary, untraded, base-form, non-fateful English B2/W2 eggs. It removes every move with an initial/egg/machine alternative before checking relative shared-level order. Every compatible TM/HM entry is included as an overapproximation; an unavailable machine cannot manufacture a rejection. There are no specimen ID or species exception lists. The independent comparison proof uses 649 source-derived rows, checksum/domain guards and a fixed index hash; CI rebuilds the index from clean official release resources.

Pidgey provides a concrete pair: Tackle/Agility/Wing Attack is produced by parents knowing Agility and Wing Attack; Tackle/Wing Attack/Agility cannot be produced by the pinned shared-level traversal. Neither move has an initial, egg or machine alternative. PKHeX's full report **and standalone chain** accept both exact inputs. NX now accepts the first and rejects the second. Its raw pair agreement remains **1/2**, raw false Invalid **1**, independently explained native-order disagreement **1**. Nothing is subtracted from the measurements. The Japanese-language derivative remains Incomplete because its regional binary has not been independently replayed.

This is stronger mechanism evidence than the reference's possession-only result for this scoped pair; independent original-ROM rebuild/custody remains an explicit limitation. The replay also exercises parent sorting, Ditto cases and Light Ball. It is not a complete breeding/event proof.
