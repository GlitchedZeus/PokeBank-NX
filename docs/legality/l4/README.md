The audit's all-UNVERIFIED grade is deliberate: the source database and archive notes cannot assign original provenance to individual rows, dates, language windows or converted gift payloads. Nothing in this tranche verifies actual retail distribution, historical fixed initial moves, original OT/nickname trash bytes, native ribbon words, release dates, or later teachable move histories. A conditional source with injected "verified" flags is a *hypothetical model test*, never an authenticated event.
