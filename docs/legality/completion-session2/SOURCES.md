- [Nintendo's Japanese Crystal manual](https://www.nintendo.co.jp/data/software/manual/304177.pdf) page8 shows the trainer-name input screen, including question/exclamation punctuation. Page17 documents move rearrangement. Its Time Capsule section documents earlier-generation communication. This is official VC documentation, not an authenticated original-cartridge capture; that limitation is retained. The original [Gold/Silver site](https://www.nintendo.co.jp/n02/dmg/kingin/index.html) independently documents Gen I communication and the foreign-language warning. Native link code preserves the OT bytes; a Gen II trainer name need not originate on the Gen I naming screen.
- [The official Pokémon Celebi page](https://www.pokemon.co.jp/ex/VCCR/171214_02/) explicitly states that the original Game Boy Color Crystal could receive special Mobile Adapter news and obtain Celebi. It separately describes the VC replacement. This is first-party retrospective authentication of availability, not an inference from the presence of an unused ROM script. The Japanese disassembly lead's IlexForest script loads CELEBI at30 as a wild encounter. Its README lists the Japanese ROM SHA1, but we did **not** independently rebuild that Japanese disassembly. Do not claim an authenticated 2001 news payload, exact campaign dates or individual receipt records.
