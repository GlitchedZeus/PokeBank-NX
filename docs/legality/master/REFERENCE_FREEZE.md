## Standard source record for a new rule
`catalog_id | exact retail source game | source repo and SHA | source path/symbol | source/dataset digest | extracted rule summary | license confidence | archived event grade | supporting native fixture IDs | unsupported alternatives | risk of false Invalid`.

A rule is **ready for coding** if the game-specific mechanism and original data ownership are independently pinned, the initial/collection-time historical stage can be represented, and native positive/contradiction/Unknown cases are specified. A rule is **research-blocked** if original mechanics or required source are unknown. A rule is **fundamentally unobservable** when a detached specimen cannot reveal original parents/MT stream/trade history; source-attested hypothetical checking is valid only within its stated witness scope.

Research-only test plans are not executed passing tests; source hashes are not legality verdicts; original retail source references are not evidence that a particular uploaded Pokémon is authentic.
