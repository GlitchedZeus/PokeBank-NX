Corrections to the supplied research:

- Native Pokémon language IDs are **4 Italian /5 German**, not the reverse. This is visible in archived bytes and the primary PKHeX enum. One unreleased file labelled ITA actually contains raw language7 and duplicates a Spanish file: filenames are not evidence of the byte interpretation.
- Raw full-card game flags are not the low-nibble PGF catalog flags. Observed masks0x10(B),0x20(W),0x30(BW),0xF0(all four) have archive witnesses. Isolated sequel bits and unobserved/unknown combinations stay Unverified.
- The blank full-card date differs from a catalogued received PGF. Exact comparison remains exact. Only bytes0xAC..0xAF receive an explicit date-only relation; every other byte must match and a substituted receipt date must be a valid calendar date.
- WORLD11 Scrafty(KOR), catalog index14: archived paired claim0x83 versus newer catalog annotation0x23. Both bytes are retained. This is an unresolved metadata/provenance disagreement, not permission to certify Korean receipt or reject English alternatives.
- A valid CRC proves integrity under a documented algorithm, not original distributor authenticity. Recomputed-CRC tampering is rejected by the pinned source hash checks.
