# EVENT-001 / MOVE-001 — single Gen IV event identity and move history

The existing 247-card PCD template projection identifies a possible event's species/PID/trainer/met/ball fields but **omits initial moves, OT raw text and ribbons**. A matching card is not proof of actual release or receipt. A four-move hypothetical historical witness must therefore require independently verified initial moves for a **single claimed nonzero event card**, without combining gifts with incompatible identities.

This helper uses the pinned native Gen IV template matcher, then attaches retained initial-move evidence to one event ID and conditionally combines independently verified later level/tutor/machine witnesses. A special move from another event card is excluded from *that candidate*, while ordinary post-event learning is still possible. The original event may have evolved; no assumption that all starting moves remain currently held.

Results are **candidate-scoped**, not global decisions. Unknown initial move payload yields Unknown; incomplete later learning yields Unresolved; contradiction excludes only the asserted fully enumerated candidate. Tests use pinned event **identity** Charmander card #67 with *synthetic, explicitly hypothetical* starting moves. No actual raw event moves or source archive files are imported, and none of these tests purports to prove a retail distribution or produce a native PK4 fixture.

No writes, auto-fixes, or global Invalid classification.
