## Implemented, not inferred

`Gen56PkhexChronologyCore.h` is a **bounded, read-only candidate-proof gate** with exact original cartridge titles (Diamond/Pearl/Platinum/HGSS, Black/White/B2W2, X/Y/ORAS), authenticated individual/candidate and immutable intermediate snapshots, contiguous stage identities, monotone levels, source-owned method and item receipts, already-known/declined level-up offers, move deletion and replacement, stage-authenticated evolution/form change and game visits.

Two explicit transfer types require **independently attested source/departure/immediate-arrival snapshots and transfer proof fields**. `PokeTransfer4to5` never treats an arbitrary PK5 with a Gen IV origin flag as proof of an original PK4. `BankTransfer5to6` never treats an arbitrary PK6 with a Gen V origin flag as proof of original PK5 or transporter custody. The checker does not invent unverified destination met/egg marker values, mutate source data or perform the product's native PK5 decoding (PR #300 owns this).

The machine mapper **proves only original machine ID → move mapping**. It does not prove a particular species/form is compatible, the player owned the item, a tutor was accessible, a level-up offer happened or a transfer service occurred. A valid hypothetical positive therefore requires an external verified `speciesCompatibleAuthenticated`, `originalSourceRecord`, original action and (for levels) `allIntermediateLevelDecisionsAuthenticated`. No unverified Gen V/VI learnset or machine compatibility matrices have been silently invented. A future original table adapter will need the `lvlmove_bw.pkl`, `lvlmove_b2w2.pkl`, `lvlmove_xy.pkl`, `lvlmove_ao.pkl` and original per-title personal records, or exact native independently verified equivalents.

**Verdict boundary:** `CandidateConsistent` means *this particular proposed, fully attested hypothetical sequence matches move-slot mechanics and bounded source table mappings*, not a real Pokémon is legal. `CandidateContradicted` applies only to this claimed candidate; no global Invalid is authorized. Missing historical evidence or an unsupported method yields `Unknown`. Every action is preflighted, so a later Unknown pre-empts any earlier candidate-local contradiction. Alternative histories remain Unknown unless fully enumerated — and a detached native record is not proof of complete enumeration.
