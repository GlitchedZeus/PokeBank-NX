## B16 implementation and model

New **`include/Legality/Gen4EggIVHistoricalCandidateSet.h`** evaluates up to 16 independently identified IV-stage hypotheses for one explicit original-stage child and physical daycare parent pair. Each hypothesis is supplied with a unique route ID, source-attested shared stage ID, source-attested historical held items, and a source-attested known final LCRNG state. It replays through the accepted `Gen4EggIVInheritanceStage::verifyKnownFinalStage`, including HGSS no-Power **6**, one-Power **4**, and two-Power **5** draws (two holders select exactly one forced donor/stat; two identical items still consume the holder selection draw). Physical deposited slots are never inferred from the male/female move donor role. Power Weight/Bracer/Belt/Anklet/Lens/Band are respectively item IDs 294/289/290/293/291/292.

New **`include/Legality/Gen4NativeBreedingIVHistory.h`** derives parent and original child **IV bytes only** from immutable validated encrypted native PK4 snapshots. The same original egg and both parents require externally attested source-game container, original unhatched egg, both original parent snapshots, original physical deposit order and shared event identity. The native child's current PID/IVs, parent held item or trainer data are not used to fabricate missing historical PID state, held-item history or LCRNG seed; `originalInitialChildIVs` must be independently supplied because final child IVs cannot reconstruct pre-inheritance rolls.

**Candidate-local classification:** `ConditionalHistoryMatched` denotes a compatible supplied hypothetical IV stage, not a legal whole egg. `AllEnumeratedStageHypothesesContradicted` means only *the fully supplied and independently enumerated finite IV-stage hypotheses* contradicted; it never means the PK4 is globally Invalid. Duplicate route IDs, stage mismatch, unknown collection-time Power items, missing LCRNG state, missing historical parents, no independent egg-stage proof, malformed records and bounded-incomplete enumeration cannot produce a global verdict. Alternative egg origins, missing parents, transfers and history erasure remain unresolved.
