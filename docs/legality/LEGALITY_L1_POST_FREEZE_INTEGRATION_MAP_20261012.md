Source Eevee→Jolteon with witnessed Gen I chain still yields only `ConditionalOriginalSource`. When both time and Crystal caught-data are witnessed, they must agree. Unrestricted time masks need no new proof. Gold/Silver lack Crystal caught-data, so missing original clock stays unknown. The Gen II native test matrix covers all nine method classes in G/S/C, positive explicit clock, missing-clock Unknown, Crystal caught-data substitution, conflicting recorded clock and bad time range.
3. **Cross-family aggregation** (`Gen14EncounterCandidateUniverse.h`): unsupported `Family::Count`/invalid family index or invalid evidence enum now produces `UnknownOriginalHistory`, not invented conditional match or dropped observation. Native compile-time matrices cover missing acquisition history, three independent local negatives plus unverified event/gift or transfer alternative, all 14 supported families locally contradicted (still `globalInvalidSupported=false`), malformed family and malformed status. Gen1/Gen2 newly typed Unknown results map to Unknown; never to global Invalid.
